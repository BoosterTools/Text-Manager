# App Icon

Drop a Windows `.ico` file here named `app_icon.ico` (e.g. 256x256, multi-resolution)
to brand the application window, taskbar entry, tray icon, and the built .exe.

If no icon is present, the app automatically generates a simple purple "T"
monogram icon at runtime so it still runs and builds correctly without one —
this is just for polish.

Recommended: export a `.ico` with sizes 16, 32, 48, 256 embedded (most icon
generators/converters, e.g. an online PNG-to-ICO tool, do this automatically).
